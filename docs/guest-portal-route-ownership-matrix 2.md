# Guest Portal Route Ownership Matrix

This matrix is the Phase 1 safety baseline for keeping Guest Portal thin while the remaining migration work lands. Runtime callers should use `apps/guest-portal/lib/api/client.js` and the generated contract in `apps/guest-portal/lib/api/generated/guest-v1.js`.

| Surface | Frontend owner | Generated operation(s) | Gateway owner | Backend/core owner | Data/services |
| --- | --- | --- | --- | --- | --- |
| Auth bootstrap/login/register/logout/password/OTP | `components/providers/AuthProvider.jsx`, login/signup/forgot-password clients | `getGuestAuthBootstrap`, `loginGuest`, `registerGuest`, `logoutGuest`, `checkGuestEmail`, `changeGuestPassword`, `requestGuestPasswordReset`, `sendGuestOtp`, `verifyGuestOtp` | `routes/v1/auth.ts` | `lib/guest-auth.ts`, Firebase auth helpers | Firebase Auth, `users`, guest profile docs |
| Guest profile update/avatar/lookup/public profile | profile/edit/profile-query clients | `updateGuestProfile`, `createGuestProfile`, `uploadGuestAvatar`, `lookupGuestProfile`, `getGuestPublicProfile` | `routes/v1/profiles.ts`, `routes/v1/guest-profiles.ts` | guest profile helpers/services | Firestore profile/user docs, Storage |
| Public discovery and SEO | homepage/explore/event/host/venue pages and clients | `listPublicEvents`, `listFeaturedEvents`, `getPublicEvent`, `listPublicHosts`, `getPublicHost`, `listPublicVenues`, `getPublicVenue`, `searchPublicDiscovery`, homepage ops | `routes/v1/public.ts` | `services/public-discovery.ts`, `guest-discovery-engine.js` | public read models, events, hosts, venues |
| Promoter public links | handle/event RSVP surfaces | `getPublicPromoter`, `resolvePromoterVanityLink`, `trackPromoterLinkClick` | `routes/v1/guest-promoters.ts`, `routes/v1/promoter-links.ts` | promoter/link engines | promoter profiles, promoter links/clicks |
| Checkout quote/reserve/initiate | `components/CheckoutContainer.jsx`, checkout page clients | `calculateCheckout`, `validateCheckoutPromo`, `reserveCheckoutInventory`, `initiateCheckout` | `routes/v1/checkout.ts` | `checkout-service`, `pricing-engine`, `promo-service`, inventory/order engines | reservations, orders, inventory, promo docs, Redis locks |
| Payments and confirmation | checkout, confirmation, cancel order surfaces | `getPaymentConfig`, `createPaymentOrder`, `verifyPayment`, `getGuestOrder`, `requestOrderCancel` | `routes/v1/payments.ts`, `routes/v1/orders.ts` | checkout/order/refund services | orders, payments, Razorpay |
| Tickets wallet/share/claim/pair/transfer | tickets page, claim/pair pages, ticket modals | `getGuestTickets`, ticket share/claim/pair/transfer ops, cover-wallet ops | `routes/v1/tickets.ts`, `routes/v1/cover-charge.ts` | wallet/profile/notification service, ticket share engine, cover charge engine | tickets, orders, transfer/share docs, cover wallets |
| Event actions and waitlist | event detail, queue pages, intent replay | `recordEventView`, `trackEventInteraction`, `setEventRsvp`, `getEventQueue`, `joinEventQueue`, `joinWaitlist` | `routes/v1/events.ts`, `routes/v1/waitlist.ts` | event/queue/waitlist engines | events, queues, waitlists, analytics |
| Follow and venue reservations | host follow CTA, venue page, reservation modal | `getFollowStatus`, `followEntity`, `unfollowEntity`, `getVenueFollowStatus`, `followVenue`, `unfollowVenue`, `createVenueReservation` | `routes/v1/social.ts`, `routes/v1/venue-settings.ts` | follow graph / venue services | follows, venues, reservations |
| Guest notifications and passes | notification/ticket wallet surfaces | `listGuestNotifications`, `updateGuestNotifications`, `getAppleWalletPass`, `getGoogleWalletPass` | `routes/v1/guest-notifications.ts`, `routes/v1/guest-passes.ts` | notification/pass engines | notifications, pass payloads |

Acceptance rule: adding a Guest Portal request requires adding or updating one row here, one generated operation, and a route-boundary test.
